# 1人営業のための無料サンプル

CRMを買うほどではない、1人〜数人の営業・小規模事業者のための無料サンプルです。無料・登録不要で、実績づくりと「小さな自動化の入口」として公開します。

## 中身

- `index.html` — 公開ページ（チェックリスト、プロンプト3本、チェッカーの説明とダウンロード）
- `followup_free.py` — フォロー期限チェッカー。CSVを読み、期限切れ／今日／明日／今週／それ以降に分類します。外部送信なし、ファイル読み込みと画面出力のみ
- `customers-sample.csv` — 架空のサンプルデータ5件

## 使い方

```bash
python3 followup_free.py --csv customers.csv
# 基準日を指定する場合
python3 followup_free.py --csv customers.csv --date 2026-10-31
# レポートをMarkdownで保存する場合
python3 followup_free.py --csv customers.csv --out report.md
```

CSVの列名は `顧客名, 次アクション, 次アクション日`（日付は YYYY-MM-DD）で固定です。

## 注意

- AIの出力をそのまま送信しないでください。宛名・金額・日程・約束内容は原文と照合してください。
- 顧客の個人情報を公開リポジトリや不特定のAI入力にそのまま載せないでください。このリポジトリのサンプルは全て架空のデータです。

## 有料版について

全12本のプロンプト＋顧客・案件管理シートの設計＋自動抽出の説明は、18歳以降に有料版として公開予定です（予告のみ。価格・販売場所はその時点で公式手数料を再確認して決めます）。
